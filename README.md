# AMANA PACKAGING

Application de stock, ventes et factures (film étirable et film à bulles d'air).

## Publier sur GitHub Pages
1. Créez un dépôt GitHub (public ou privé).
2. Envoyez à la racine du dépôt les 7 fichiers : `index.html`, `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `apple-touch-icon.png`.
3. Dépôt > Settings > Pages > Source : « Deploy from a branch », branche `main`, dossier `/ (root)`, puis Save.
4. Après une minute, l'application est disponible sur `https://VOTRE-NOM.github.io/NOM-DU-DEPOT/`.

## Installer sur le téléphone
Ouvrez le lien dans Chrome (Android) ou Safari (iPhone), puis « Ajouter à l'écran d'accueil ».

## Données
Les données (stock, ventes, clients, factures) sont enregistrées dans le navigateur de l'appareil. Elles ne sont pas partagées entre deux appareils.
